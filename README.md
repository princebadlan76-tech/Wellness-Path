# Wellness Path

A clean, responsive static frontend website template built for fitness and health blogs, optimized for search engines and ad monetization.

## Setup Instructions

1. Create a new repository on GitHub named `wellness-path`.
2. Upload all the files (`index.html`, `style.css`, `script.js`, `about.html`, `privacy.html`, `disclaimer.html`, `affiliate-disclosure.html`, and `contact.html`) to the root folder.
3. Import the repository into [Vercel](https://vercel.com/new).
4. Set Framework Preset to **Other** and Output Directory to `.` (root).
5. Deploy!
